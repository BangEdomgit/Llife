# Llife

era 텍스트게임 느낌의 인생 시뮬레이션. 0살부터 50살까지, 50살에 오픈 엔딩.

## 실행

`index.html`을 브라우저로 열면 바로 돌아감 (서버 필요 없음). 진행 상황은 브라우저에 자동 저장됨.

## 1년의 흐름

- 1년에 행동 10번. 행동을 쓰는 만큼 계절이 넘어감: 봄(0) → 여름(3) → 가을(6) → 겨울(8)
- 계절 안에서도 행동을 쓸수록 아침 → 낮 → 저녁. 계절의 마지막 행동은 늘 저녁 (술집은 저녁에만 열림)
- **장소**: 먼저 장소를 고름(행동 1) → 거기 있는 사람에게 말 걸기(행동 안 씀, 한 사람에 한 번) 또는 장소 행동(행동 1). `돌아가기`로 다른 장소를 고름
- 고정 이벤트는 봄·여름·겨울에 한 번씩, 1년에 3번 (입학·수능 같은 필수 이벤트가 있으면 그게 먼저)
- 랜덤 이벤트는 행동한 뒤에 가끔 (산책하다 지갑 줍기, 운동하다 사람 만나기 등)
- 남은 행동은 `1살 먹기`를 누르면 쉬면서 보냄 (계절 이벤트는 그대로 터짐)

## 시작할 때 고르는 것

이름, 성별, 소질(9), 성격(8), 집안(6), 취미(8), 가치관(6), 꿈(10), 형제(6), 생일(12). 전부 랜덤도 가능.

## 시스템

- **능력치**: 행복·건강은 0~100 상태값. 지능·체력·생김새·꾸밈·매력·감성·손재주는 상한 없이 F~SS 등급으로 오르고, 등급이 높을수록 오르기 어려움
- **외모 3층**: 생김새(타고남, F~A 랜덤 / 소질 '타고난 외모'면 B~S, 40살·45살에 한 등급씩 내려감, 20살부터 성형으로만 오름) · 몸(체력 등급 그대로, 운동 안 하면 빠짐 — 20대는 잘 오르고 40대는 유지도 어려움) · 꾸밈('꾸미기'·'쇼핑'으로 오르고 매년 20~30 떨어짐, 감성이 높으면 더 잘 오름). NPC도 생김새·꾸밈 등급과 체형(키·체격·가슴/어깨), 좋아하는 체형이 있음. 체형은 처음엔 키와 대략적 체형만, 친밀 30이면 인상, 50이면 취향, 60이면 쓰리 사이즈, 함께 밤을 보내면 전부 보임 (20살 이상만)
- **학교**: 13살부터 국어·수학·영어·탐구 실력이 따로 쌓임. 고등학교 학기마다 내신, 모의고사, 수능 등급. 환산 등급으로 가·나·다군 대학 지원, 합격하면 전공 선택, 대학에선 학점
- **직업**: 18종. 학력·전공·학점·능력치 등급 조건, 직급과 성과, 승진, 직업마다 전용 이벤트
- **사람 정보**: 나와 NPC 모두 성격·취미·가치관·집안·꿈(또는 직업)·특징을 가짐. NPC 정보는 친해질수록 하나씩 보임. 성격 궁합, 같은 취미, 가치관이 관계 변화에 영향

- **장소**: 19곳 (집, 놀이터, 공원, 학교, 학원, 대학, 직장, 카페, 도서관, 헬스장, PC방, 번화가, 병원, 복지관, 터미널, 술집, 종교시설, 편의점, 공연장). 나이·직업·학생 여부·시간대에 따라 열림. 가면 아는 사람 몇 명과 처음 보는 사람이 있고, 처음 보는 사람은 말을 걸어 성공하면 이름과 특징이 드러나고 관계 목록에 들어감. NPC마다 자주 가는 곳(hangout)이 있어서 거기 가면 잘 마주침. 같은 곳에 3번 가면 단골이 되고 단골 전용 이벤트가 생김
- **성욕**: 20살부터 플레이어와 NPC 모두 0~100. 행동할 때마다 오름(20대 3~4, 30대 2~3, 40대 1~2, 건강 50 이하면 절반). 60이 넘으면 행동마다 행복 -1 대신 꼬심 보너스. 집에서 '자위'(-40~50), 함께 밤을 보내면 -70~90. 같이 있으면 서로 몸 등급만큼 더 자극됨
- **섹스 스탯**: 기술(F~S, 경험으로 오름), 크기(남자만, 타고남, 함께 밤을 보낸 뒤에만 보임), 상대별 궁합(같은 상대일수록 오름). 만족감 = 기술 40% + 궁합 25% + 크기 10% + 설렘 15% + 분위기 10%. 만족감에 따라 상대 설렘이 크게 오르거나("잊을 수가 없다") 오히려 내려감("한 번이면 됐다"). 첫 경험은 낮아도 설렘이 오름
- **꼬심 공식**: 외모(생김새·몸·꾸밈) + 인간(매력·감성) + 관계(설렘·친밀) + 보정(상대 성격, 선호 체형, 취미·가치관, 술집·여행지, 서로의 성욕, 기혼, 음주) ± 15. 처음 만남 / 아는 사이 / 친한 사이 / 잠자리 수락마다 가중치가 다름 (잠자리 수락은 외모가 작고 설렘·친밀·성욕·상황이 큼). 플러팅·처음 보는 사람 말 걸기·하룻밤·집으로 데려가기에 씀
- **술자리**: 술집에서 '한잔'·'같이 한잔'을 할 때마다 한잔 → 적당히 취함 → 만취. 적당히 취하면 매력·꼬심이 오르고 대사가 대담해지지만, 만취하면 매력이 떨어지고 사고가 남(전 연인에게 카톡, 엉뚱한 사람에게 전화, 길에서 잠듦, 시비, 모르는 사람에게 플러팅). 술집을 떠나면 깨고, 적당히 넘게 마셨으면 숙취(건강·행복 하락)
- **기혼 NPC**: 26살부터 나이에 따라 일부는 결혼한 사람. 친밀 20이면 반지가 보이고 40이면 기혼인 걸 알게 됨(또는 "사실 나 결혼했어"). 늘 몰래 만나는 사이로만 시작하고, 들킬 길이 둘(내 애인에게 / 상대 배우자에게). 설렘·신뢰가 아주 높으면 이혼하고 오기도, 설렘이 식으면 가정으로 돌아가기도 함
- **아바타**: NPC마다 상반신 그림이 있음. 얼굴형·피부색·머리 모양·머리색·눈·눈썹·입·안경·옷을 조합해 SVG로 그림 (이미지 파일 없음). 같은 사람은 늘 같은 얼굴이고, 나이에 따라 바뀜 (어린이는 단순한 머리, 10대는 교복, 40대부터 흰머리). 특징이 "안경을 썼다"면 안경, "주근깨가 있다"면 주근깨가 그려짐. 가족·아이는 나와 피부색이 같음
- **관계**: 사람마다 친밀 / 신뢰 / 설렘 / 원한 4가지 호감도. 가만두면 조금씩 멀어짐
- **연애**: 설렘은 플레이어와 상대 모두 19살 이상, 상대 50살 미만, 이성, 가족이 아닐 때만 움직임
- **얽힌 사이**: 애인이 있어도 다른 사람과 몰래 만날 수 있음. 들키면 결과가 따라옴
- **죄책감**: 떳떳하지 못한 관계(상대가 기혼·애인 있음·나와 몰래 만나는 중)에서 상대가 느끼는 죄책감 = 성격 기본값(예민 90 … 직진 10) − (만족감 − 70) × 1.5. 높으면 1~4번 만에 관계를 끊거나 자기 애인에게 털어놓고, 만족감이 높으면 죄책감이 눌림 (전용 대사). 내가 바람피울 때도 내 성격만큼 행복이 깎임
- **섹파**: 사귀지 않고 밤을 보낸 사이에서 친밀 40+, 설렘 30~60이면 제안이 옴. 서로 성욕이 차면 연락이 오고, 들킬 위험이 낮음. 설렘이 70을 넘으면 "이거 사귀는 거 아니야?", 친밀 20 이하나 만족감이 낮으면 흐지부지 끝남
- **먼저 다가오는 사람**: 내 생김새가 B 이상이면(또는 몸 A·매력 C 이상) 처음 보는 사람이 먼저 말을 걸어옴 (S면 매년, A면 2년, B면 3~4년에 한 번). 연인은 설렘·성욕이 높으면 먼저 유혹함
- **친밀한 관계**: 플레이어와 상대 모두 20살 이상(연애·설렘은 19살), 이성, 가족이 아닐 때만. 집에서만 가능. 받아줄지는 꼬심 공식(잠자리 수락)으로 정함. 내 첫 경험은 상대 성격마다 다른 한 줄과 함께 추억에 남음 (`함께 밤을 보내다`는 사귀는 사이, `하룻밤`은 사귀지 않는 사이). 술집·공연장에서 설렘이 오른 사람은 `집으로 데려가기`로 같이 집에 올 수 있음. 행위는 묘사하지 않고 한 줄로 넘긴 뒤, 다음 날 아침 상대 성격에 따라 다른 한 줄이 나옴. 처음 보낸 밤은 날씨와 함께 추억 앨범에 남음
  - 결과: 사귀지 않는 사이면 관계가 `썸` / `복잡한 사이`로 바뀜. 애인이 있으면 들킬 위험(`affairCaught`), 상대에게 애인이 있으면 그쪽에 들킬 위험(`rivalFound`)
  - 임신: 확률이 발동하면 다음 계절에 소식이 옴. 배우자면 내년에 출산, 아니면 선택지 (결혼 / 같이 키우기 / 책임만 지기 / 못 본 척, 내가 임신했으면 말하기 / 결혼하자고 하기 / 혼자 키우기). 엄마 나이 30살부터 확률이 줄고 45살부터는 0
- **범죄**: 돈은 되지만 경찰의 관심이 쌓이고, 몇 년 뒤에라도 잡힐 수 있음. 보이지 않는 업보는 다른 모양으로 돌아옴
- **추억**: 큰 사건은 그때 계절·날씨와 함께 앨범에 저장되고 엔딩에서 보여줌
- **이벤트**: 약 330개. 장소별(19곳 + 단골), 직업별(18종 × 4~6개), 관계 심화(기념일, 동거, 질투, 상견례, 신혼여행…), 친밀한 관계, 가족(부모님 은퇴, 명절, 아이 사춘기, 조카…), 건강(허리, 불면증, 번아웃, 금연…), 돈(전세 사기, 주식 폭락, 복권, 보이스피싱…). 계절 일상 한 줄도 계절 × 시기마다 6개씩

```

js/avatar.js        NPC 상반신 아바타 (파츠 조합 SVG)
js/game.js          게임 엔진 (상태, 계절, 이벤트, 관계, 범죄, 저장) — 화면은 모름

data/places.js      장소 (나이 조건, 거기 나오는 사람, 하고 있는 일, 할 수 있는 행동)

data/jobs.js        직업 (조건, 직급, 연봉)

```

## 이벤트 추가하기

`data/events.js`에 항목을 하나 추가하면 됨. 쓸 수 있는 필드는 파일 맨 위 주석 참고.
랜덤 이벤트의 `on`에는 행동 id(`walk`)뿐 아니라 장소 id(`cafe`)도 쓸 수 있음. 장소 id를 쓰면 그 장소에 도착했을 때나 거기서 행동할 때 터짐.
`{fp|와}`처럼 쓰면 이름과 조사(와/과)가 자동으로 맞춰짐.

개발할 때는 브라우저 콘솔에서 `Game.dev.fire('이벤트id')`로 이벤트를 바로 터뜨려볼 수 있음 (`Game.dev.eligible('id')`로 지금 조건이 맞는지 확인).
